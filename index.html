Construindo a resposta

1. Se os lados do terreno medem x e y, como representar os 24 metros de cerca?
Gabarito para comparar
2x + 2y = 24

O perímetro soma dois lados de cada medida.

2. Se escolhermos a medida x, quanto deve medir o outro lado?
Gabarito para comparar
y = 12 − x

Os dois lados diferentes somam 12 metros.

3. Como escrever a área usando apenas x?
Gabarito para comparar
A(x) = x · (12 − x)

A área é o produto das duas dimensões.

4. O que acontece com a área quando x aumenta?
Gabarito para comparar
A(x) = 12x − x²

Compare o gráfico com os valores do jogo e localize seu ponto mais alto.

5. Qual função podemos escrever para encontrar, não só a maior área como todas as áreas?
Gabarito para comparar
A(x) = 36 − (x − 6)²

Como um quadrado nunca é negativo, A(x) ≤ 36. A igualdade ocorre quando x = 6; então y = 6. Logo, a área máxima é 36 m².
